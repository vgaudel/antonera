Démonstration du Control Flow Angular

1. @if

@if (isLoggedIn) {

Vous êtes connecté

} @else {

} @if(isLoggedIn){

Rôle de l'utilisateur

@if(userRole==='admin'){

✏️ Éditeur

👤 Invité

2. @for avec track et @empty

Liste de fruits:

    @for (fruitItem of fruits; track fruitItem){
  • {{fruitItem}}
    • }

Liste des utilisateurs (avec index)

    @for (userItem of users; track $index){
  • {{$index+1}}. {{userItem.name}}
    • }

Liste vide (@empty)

    @for (item of emptyList; track item){
  • {{item}}
    • } @empty {
  • Aucun élément à afficher
    • }

3. @switch / @case / @default

@switch (status) { @case ('loading'){

Chargement en cours ...

} @case ('success'){

Opération réussie !

} @case ('error'){

Une erreur est survenue.

} @default {

État inconnu.

} }

4. @let (variable locale au template)

@let fullname = firstname + ' ' + lastname;

Nom complet : {{fullname}}

En majuscule : {{fullname.toUpperCase()}}
